Everything here is a screenshot of the running service, not a mock-up.
`banner.png` is the exception and the only drawn one: it carries the name
and the tagline rather than any part of the interface, so it does not age
with the pages.

Taken against a stack of its own -- own project name, own volumes, seeded
with one demonstration account, six links and a month of visits -- so the
figures in them are consistent from picture to picture: six links, 4041
clicks. The addresses in the journal are from the documentation ranges
(`203.0.113.0/24`, `198.51.100.0/24`), reached by trusting the stack's own
gateway, so no real address is published.

Screenshots age faster than prose, so there are few of them, and each one
shows something the text cannot say on its own.
