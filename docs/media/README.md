# Media

Screenshots, GIFs and video for the README and the guides.

| Name | Where it is used | Notes |
|---|---|---|
| `demo.gif` | The README, above the fold | 1280×720 or wider, under 10 MB. A GIF because GitHub does not autoplay video in a README |
| `dashboard.png` | The README or the tutorial | A still of the panel |

Keep the originals here too if they are large — a 30-second capture is
easier to re-crop than to re-record.
